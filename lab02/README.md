# Лабораторная работа 2. Классы и инкапсуляция

## Цель работы

Научиться создавать собственные классы, проверять входные данные и защищать состояние объектов с помощью инкапсуляции.

## Вариант

Инженерия систем искусственного интеллекта.

## 1. Класс DataSample

Класс DataSample описывает наблюдение, содержащее идентификатор, метку, статус и массив числовых признаков.

Основные операции:
- создание наблюдения с проверкой входных данных;
- изменение статуса через changeStatus;
- проверка готовности наблюдения через isReady;
- вычисление среднего значения признаков через calculateAverage.

### Инварианты

- Идентификатор и метка не равны null и не содержат только пробелы.
- Статус не равен null.
- Массив признаков не равен null и не является пустым.
- Все признаки являются конечными числами.
- Поля закрыты модификатором private.
- Массив признаков копируется при создании объекта и при возврате из getFeatures.
- Статус изменяется только через changeStatus.

## 2. Класс BankAccount

Класс BankAccount моделирует банковский счёт с целочисленным балансом.

Основные операции:
- создание счёта;
- пополнение через deposit;
- списание через withdraw;
- получение баланса через getBalance.

### Инварианты

- Начальный баланс не может быть отрицательным.
- Сумма пополнения и списания должна быть положительной.
- Списание не может превышать текущий баланс.
- Баланс изменяется только через deposit и withdraw.
- Прямое изменение баланса извне запрещено.

## 3. Тестирование

Для проверки используются тесты JUnit.

Проверяются:
- создание корректных объектов;
- отклонение недопустимых значений;
- изменение статуса наблюдения;
- вычисление среднего значения признаков;
- защита массива от внешнего изменения;
- успешное списание средств и отказ при превышении остатка.

## 4. Запуск тестов

В Windows PowerShell из корня репозитория:

    .\mvnw.cmd -pl lab02 test

Успешное выполнение тестов подтверждается сообщением BUILD SUCCESS.
